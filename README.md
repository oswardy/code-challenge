# Frontend Code Challenge – Osward Yong

## 📌 Overview ##
This repository contains my solutions for the frontend code challenge.

It includes:
- Problem 1: Three ways to sum to n (JavaScript implementations)
- Problem 2: Currency Swap Application (HTML, CSS, JavaScript)
- Problem 3: Code Review, Issue Analysis, and Refactoring (TypeScript)

## 📂 Project Structure ##
/problem1  
  - solution.js

/problem2  
  - index.html  
  - style.css  
  - script.js

/problem3  
  - explanation.txt  
  - RefactoredProblem3.tsx

## ▶️ How to Run ##

### Problem 1 ###
Run with Node.js:
node code-challenge/problem1/solution.js

### Problem 2 ###
Open in browser:
code-challenge/problem2/index.html
Internet connection is required to fetch token prices and images

### Problem 3 ###
Open the following files for review:
problem3/explanation.txt
problem3/RefactoredProblem3.tsx
